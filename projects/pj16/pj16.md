
# [PJ16] Development of Management Android Application

**Objective** Develop a management Android application with a launcher-style UI and a maintainable architecture for hierarchical management functions.<br>
**Keywords** Android, Kotlin, Jetpack Compose, Room, Flow, MVVM, View System, Crawling<br>
**Duration** 2025.02-2026.04<br>
**Proportion** <br>
**Skills** Android, Kotlin, Jetpack Compose, Room, Flow, MVVM, Crawling

<br>

## ROLE

1. Redesigned a complex hierarchical menu into a launcher-style UI and simplified nested navigation
2. Researched and implemented Jetpack Compose migration while maintaining interoperability with the existing View System
3. Built reusable generic Adapter/Base ViewHolder components to reduce duplicated Android UI code
4. Implemented data management with Room and Flow for reactive data flow
5. Implemented new features using Compose and maintained a hybrid Compose + FragmentContainerView architecture
6. Developed crawling-related functionality for management data

<br>

## OUTPUT

- Management Android Application
- Launcher-style UI redesign
- Reusable generic Adapter architecture
- Room + Flow based reactive data flow
- Hybrid Jetpack Compose / View System implementation

<br>

## WHAT I'VE LEARNED

1. Practical migration strategy from the Android View System to Jetpack Compose
2. Designing reusable UI components to reduce duplicated implementation
3. Reactive Android data flow using Room and Kotlin Flow
4. Managing navigation and interoperability in a hybrid Compose/View architecture
