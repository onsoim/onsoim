
# [PJ17] Development Full-cycle of Apple VAS Service

**Objective** Analyze Apple VAS specifications and develop an end-to-end Android solution for Apple VAS contactless services, from low-level communication to SDK and application integration.<br>
**Keywords** Apple VAS, NFC, ISO 14443, ISO-DEP, APDU, AIDL, IPC, Android Service, SDK, Jetpack Compose<br>
**Duration** 2025.11-Ongoing<br>
**Proportion** Sole owner<br>
**Skills** Kotlin, Android, NFC, ISO 14443, ISO-DEP, APDU, AIDL, IPC, Jetpack Compose

<br>

## ROLE

1. Independently lead the Apple VAS technical work and certification process
2. Analyze Apple VAS protocol behavior and raw APDU command/response sequences
3. Design an Android-optimized communication layer over ISO-DEP
4. Design a reusable interface-based architecture for heterogeneous contactless protocols and future standards
5. Design the communication architecture considering Android's foreground execution constraint for NFC operations
6. Implement NFC polling and tag detection in the SDK, and delegate APDU processing and data decryption to a background service
7. Design an AIDL-based IPC interface between the SDK and background service to exchange detected tag data and processing results 
8. Develop an Android background service using AIDL IPC to encapsulate communication and cryptographic processing behind stable APIs
9. Develop an SDK that abstracts APDU communication and provides a simple interface to application developers
10. Develop and integrate the Demo application, SDK, and Service as an end-to-end solution
11. Controlled ECP (Enhanced Contactless Polling) through the NFC HAL and validated interoperability across multiple iPhone generations

<br>

## OUTPUT

- End-to-end Apple VAS Android solution: Demo Application - SDK - Service
- Android communication architecture separating NFC polling/tag detection from APDU processing and data decryption
- AIDL-based Android IPC service
- Reusable contactless communication architecture
- SDK abstraction for APDU communication
- Apple VAS certification currently in progress

<br>

## WHAT I'VE LEARNED

1. Analyzed and implemented contactless communication at the ISO-DEP and APDU level
2. Designed Android middleware considering platform execution constraint and separation of responsibilities between SDK and background service
3. Designed AIDL-based IPC communication between application-facing SDK and background service
4. Built an end-to-end architecture spanning application, SDK, Android service, and low-level communication
5. Gained practical experience with Apple VAS certification and protocol validation
