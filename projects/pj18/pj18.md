
# [PJ18] Development of newly applied VAN (NICE)

**Objective** Implement NICE VAN key-download functionality and integrate the required APIs into the existing Linux terminal firmware for a new customer.<br>
**Keywords** VAN, DIK, Key Download, Linux, C, API, Android<br>
**Duration** 2026.05-2026.06 (2 months)<br>
**Proportion** Sole owner of the Linux terminal work<br>
**Skills** C, API, Linux, Android

<br>

## ROLE

1. Implement the NICE VAN key-download process based on the DIK provided by NICE
2. Implement the process for obtaining initial keys, renewal keys, and PMK
3. Collect and manage required terminal information and uniquely assigned DIKs for each terminal
4. Develop a dedicated Android application to support terminal and DIK management
5. Add APIs required for the new customer to the existing terminal firmware
6. Validate the key-download and integration flow on Linux terminals
7. Independently handle the Linux-terminal development and integration

<br>

## OUTPUT

- NICE VAN key-download implementation
- Android application for terminal information and DIK management
- New-customer APIs integrated into existing Linux terminal firmware
- Passed the required security certification and completed registration with the Korea Credit Finance Association (여신금융협회)

<br>

## WHAT I'VE LEARNED

1. Practical understanding of VAN key management and key-download flows
2. Integrating customer-specific APIs into existing terminal firmware
3. Managing device-specific identity and key information across Android and Linux components
4. End-to-end responsibility for Linux terminal implementation, integration, and security certification
