
# [PJ19] Development of Key Management Android Application



**Objective** Develop and Android application for DIK management, integrating with MES services and supporting heterogeneous terminals with different SDKs<br>
**Keywords** Android, Kotlin, MES, DIK, Key Management, Server Authentication, Multi-Device, SDK Integration<br>
**Duration** 2026.05-2026.06 (2 months)<br>
**Proportion** 100% (Sole)<br>
**Skills** Kotlin, Android, MES, Authentication, SDK Integration

<br>

## ROLE

1. Designed and developed an Android application for DIK management
2. Implemented communication with the MES service using the terminal serial number to manage DIK_SN and DIK
3. Implemented server authentication and secure communication between the Android application and MES service
4. Designed the application to supprot multiple terminals using different product SDKs through common application structure
5. Integrated terminal-specific SDKs while maintaining a common application-level interface
6. Ensured application compatibility across Android versions 5-13
7. Integrated and validated the complete flow from terminal identification to DIK management

<br>

## OUTPUT

- Android-based terminal and DIK management application
- MES service integration for terminal information and DIK management
- Server authentication and communication flow
- Common application structure supporting heterogeneous terminal SDKs
- Android compatibility across versions 5-13
